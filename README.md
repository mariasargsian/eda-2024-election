# EDA: Президентские выборы США 2024

*[Read this in English](README_EN.md)*

Разведочный анализ электоральной географии президентских выборов США 2024 года: классификация штатов на конкурентные (swing) и предсказуемые (safe), проверка устойчивости стандартного порога классификации, анализ голосования за третьи партии.

## Executive Summary

- Выявлено 8 штатов с разрывом голосов между партиями менее ±5% («swing states»), включая Minnesota и New Hampshire — штаты, ранее не относившиеся к традиционному ядру колеблющихся.
- Проверка устойчивости порога классификации (±5%) показала, что граница — методологическая условность, а не естественный разрыв в распределении данных.
- Голосование за третьи партии концентрируется в электорально предсказуемых штатах (как демократических, так и республиканских), а не в конкурентных — наблюдение согласуется с гипотезой «protest voting», но не доказывает её причинно.

## Данные

Источник: [MIT Election Data + Science Lab](https://electionlab.mit.edu/) — результаты голосования по кандидатам в разрезе штатов, президентские выборы 2024 года.

Файл `2024-president-state.csv` не включён в репозиторий (см. `.gitignore`) — скачайте его напрямую с сайта MEDSL и поместите в корень проекта перед запуском ноутбука.

## Ограничения анализа

- Анализ проведён на уровне штатов и не учитывает внутриштатную географическую неоднородность.
- Разрыв в доле голосов по штату не тождественен электоральной значимости штата в коллегии выборщиков.
- Категория `OTHER` объединяет разнородных по идеологии кандидатов.
- Данные отражают версию по состоянию на дату публикации источника (см. столбец `version` в датасете); возможны последующие уточнения.
